# Jon2 Builder — النسخة التأسيسية

هذه الصفحة جزء من مشروع Jon2 AI وليست موقعًا منفصلًا.

## الموجود حاليًا
- واجهة عربية RTL متجاوبة مع الهاتف.
- محرر HTML وCSS وJavaScript بثلاثة ملفات.
- معاينة داخل iframe مع sandbox وبدون منحها صلاحية الوصول إلى نفس أصل الصفحة.
- إنشاء مشروع ابتدائي من وصف المستخدم؛ هذا لا يُعد توليدًا ذكيًا للكود.
- حفظ المشاريع محليًا في LocalStorage على الجهاز والمتصفح الحالي.
- تصدير المشروع كملف JSON، وتنزيل الملف البرمجي المحدد منفردًا.
- استيراد ملف JSON بحد أقصى 2MB مع التحقق من أسماء الملفات وأنواع المحتوى وحدود الحجم.
- إعادة تسمية المشاريع وحذفها مع تأكيد قبل الحذف.
- معاينة داخل iframe معزول، مع Content Security Policy تمنع اتصالات الشبكة والنماذج والموارد الخارجية افتراضيًا.

## الحالة والقيود
- لا يوجد اتصال بمحرك Jon2 أو أي مزود ذكاء اصطناعي في هذه النسخة.
- زر «إنشاء هيكل» ينشئ قالبًا أوليًا ويضيف وصف المستخدم إليه فقط؛ لا يفهم المتطلبات ولا يكتب تطبيقًا كاملًا.
- لا يوجد حفظ سحابي أو مزامنة بين الأجهزة أو حسابات مستخدمين في Builder حتى الآن.
- لا يوجد تشغيل أوامر طرفية أو تثبيت حزم أو خادم تنفيذ للمشاريع.
- المعاينة مخصصة لملفات الواجهة الأمامية داخل iframe معزول. لا تشغّل مشاريع backend أو أوامر نظام.
- LocalStorage ليس نسخة احتياطية؛ استخدم تصدير JSON لحفظ نسخة خارج المتصفح.

## فتح الصفحة
من نسخة المعاينة على GitHub Pages بعد نشر الفرع/المراجعة: `/builder/`.
لا تُعد هذه النسخة منشورة على الموقع الرسمي تلقائيًا؛ التغييرات محفوظة على فرع التطوير فقط.

## بوابات التطوير التالية
1. اختبار الصفحة والملفات المولّدة على Safari في iPhone.
2. إضافة استيراد/استعادة ملف JSON والتحقق من بنيته وحدود حجمه.
3. تحسين إدارة المشاريع: إعادة تسمية، حذف مع تأكيد، واستعادة النسخ.
4. إضافة طبقة أدوات آمنة لتعديل الملفات مع سجل تغييرات وتراجع.
5. بناء واجهة موحدة لطلب التعديلات من محرك Jon2 الأصلي فقط.
6. قبل أي ربط: إثبات أن checkpoint الأصلي ينجح في اختبارات جودة وفهم الكود، ثم اختبارات sandbox والحدود والمهلات.
7. لا تُفعّل توليدًا آليًا أو نشرًا عامًا ولا تضع أسرارًا أو أوزان النموذج في المتصفح.

## شروط القبول قبل اعتبارها شبيهة بـ Bolt
- تعديل متعدد الملفات من تعليمات طبيعية مع عرض diff قبل التطبيق.
- تشغيل معاينة قابلة لإعادة الإنتاج، ورسائل أخطاء واضحة.
- استرجاع التعديلات وإدارة إصدارات المشروع.
- اختبارات أمنية تمنع وصول كود المعاينة إلى بيانات الصفحة أو الحساب.
- اختبار فعلي على iPhone Safari.
- قياس جودة محرك Jon2 على مهام برمجية حقيقية ومراجعة بشرية قبل فتح الميزة للعامة.
