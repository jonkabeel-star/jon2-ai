# تجهيز المسار الهجين لـ Jon2 — تدريب كامل للنموذج المساعد

**الحالة: تجهيز فقط — لم يبدأ تنزيل نموذج أو تدريب أو نشر.**

## القرار المعتمد

1. يبقى checkpoint الأصلي `jon2-last.pt` أصلًا مستقلًا دون تعديل أو دمج أوزان.
2. المسار المساعد المرشح مبدئيًا هو `Qwen/Qwen3-0.6B`؛ صفحة النموذج تسجل ترخيص Apache-2.0، وتذكر دعم أكثر من 100 لغة ولهجة. هذا لا يثبت جودة العربية أو اللهجة المصرية تلقائيًا؛ يجب اختبارهما على مجموعة Jon2 مستقلة. راجع صفحة النموذج الرسمية قبل كل تنزيل: https://huggingface.co/Qwen/Qwen3-0.6B
3. التدريب المقصود **Full-Parameter Supervised Fine-Tuning**: جميع أوزان النموذج المساعد قابلة للتحديث، وليس تدريبًا من الصفر. لا LoRA ولا QLoRA في هذا المسار. يستخدم قالب Qwen3 في وضع non-thinking أثناء إعداد البيانات والتقييم.
4. النموذج المساعد لا يصبح «Jon2 الأصلي». سيبقى منفصلًا في API والاسم والتقارير.
5. لا GPU الآن؛ لذلك لا تشغّل `train_full.py` ولا تحاول تدريبًا على iPhone أو GitHub Actions.

## حالة المستودع والبيانات التي يجب احترامها

- تقرير Jon2 الأصلي المتاح: SHA-256 المسجل `edf96971187f93642f36282e270c2d2f3a6db39565b30d7898e856a49e0eaec2`، والردود في الاختبار السابق غير مفهومة بما يكفي. لا نعتبره جاهزًا للمحادثة العامة.
- سجل البيانات الحالي يذكر أن دفعات نصية معينة مسموح بها **للبحث التجريبي الخاص فقط**؛ هذا لا يمنح إذنًا للنشر العام أو الاستخدام التجاري.
- ملفات JSONL الحوارية الثلاثة المذكورة في سجل البيانات غير معتمدة حاليًا. لا تستخدمها قبل مراجعة كل ملف وتسجيل بصمته وموافقته في manifest خاص.
- ملفات TXT المعتمدة في مسار Jon2 الأصلي يمكن أن تكون معتمدة للتدريب البحثي الخاص فقط وفق manifest الخاص الموجود لدى المالك. انسخ فقط الملفات التي راجعتها ووافق عليها إلى مجلد بيانات خاص منفصل، مع إبقاء bytes كما هي كي تتطابق بصمة SHA-256.
- لا تنسخ محادثات خاصة أو معلومات شخصية أو بيانات سرية إلى التدريب.
- لا تستخدم Wikipedia أو CC BY-SA أو أي مصدر ويب مجهول في هذا المسار ما لم تُراجع حقوقه وتُعتمد صراحة للاستخدام المقصود.
- لا تضع الأوزان أو بيانات التدريب أو manifest الحقيقي أو مفاتيح API داخل GitHub.

## الملفات

- `train_full.py`: مدرب مستقل يقرأ TXT/JSONL المحلية فقط، ويتحقق من الموافقات الدقيقة، ويقسم المحادثات كاملة إلى تدريب/تحقق لمنع تسرب أدوار المحادثة، ويشترط CUDA قبل التدريب.
- `evaluate_helper.py`: يشغّل مجموعة اختبار منفصلة على نموذج محلي، ويكتب تقريرًا ينتظر المراجعة البشرية.
- `evaluation_prompts.example.jsonl`: أمثلة اختبار فقط؛ لا تدخل التدريب مطلقًا.
- `config.example.json`: إعدادات موصى بها كبداية تجريبية وليست ضمانًا للذاكرة أو الجودة.
- `source_approvals.example.json`: قالب فارغ فقط؛ لا يوافق على أي ملف.
- `requirements-training.txt`: مكتبات مسار التدريب. ثبّت PyTorch المطابق لإصدار CUDA في جهاز GPU بدل افتراض wheel واحد لكل الأجهزة.
- `.gitignore`: يمنع إدخال البيانات الخاصة والنماذج والتقارير إلى Git.

## صيغ البيانات

### TXT

يقبل الملف الحواري المكتوب بصيغة المتحدثين المتناوبة، مثل:

```text
المستخدم: اشرح الكسور ببساطة.
Jon2: الكسر يعبّر عن جزء من كل...
المستخدم: أعطني مثالًا.
Jon2: نصف التفاحة مثال على كسر...
```

كل زوج سؤال/إجابة يصبح محادثة مستقلة. لا تستخدم ملفات نثرية أو غير موسومة بهذا الشكل.

### JSONL

كل سطر يمثل محادثة واحدة:

```json
{"messages":[{"role":"user","content":"اشرح الكسور ببساطة."},{"role":"assistant","content":"الكسر يعبّر عن جزء من كل..."}]}
```

يمكن إضافة `system` في بداية المحادثة، ويمكن أن تحتوي المحادثة على عدة أدوار user/assistant. يجب أن تنتهي برسالة assistant. لا تضع أمثلة الاختبار في هذه الملفات.

## الموافقة المطلوبة قبل التدريب

لكل ملف TXT/JSONL، راجع المصدر والحقوق والخصوصية والجودة يدويًا، ثم أضف سجلًا مطابقًا إلى manifest خاص خارج GitHub. يجب أن يطابق SHA-256 وعدد المحارف الملف الحالي حرفيًا. القالب العام فارغ عمدًا.

`intended_use` يقبل:
- `research_training`: تجارب بحثية خاصة فقط.
- `public_model`: لا يُستخدم إلا بعد إثبات حقوق التدريب والتوزيع العام.
- `commercial_model`: لا يُستخدم إلا بعد توثيق الحقوق التجارية صراحة.

وجود ترخيص للنموذج الأساسي لا يمنح حقوقًا على بيانات Jon2، وموافقة البيانات لا تلغي شروط ترخيص النموذج الأساسي.

## التشغيل عند توفر GPU

1. جهّز جهاز Linux مزودًا بـ NVIDIA GPU وCUDA، وتحقق من مساحة التخزين والذاكرة.
2. نزّل نسخة النموذج المحددة إلى مجلد محلي بعد مراجعة بطاقة النموذج والترخيص وتثبيت revision/commit محدد. لا تجعل التدريب ينزّل النموذج تلقائيًا.
3. جهّز ملفات البيانات الخاصة وmanifest الموافقات خارج المستودع. استخدم مجلدًا يحتوي فقط على المصادر التي ستدخل هذا التشغيل.
4. ثبّت PyTorch المناسب لـ CUDA، ثم:
   `pip install -r hybrid_training/requirements-training.txt`
5. افحص البيانات دون بدء تدريب:
   `python hybrid_training/train_full.py --data-dir /secure/jon2-data --approval-manifest /secure/source_approvals.json --preflight-only`
6. بعد اجتياز المراجعة وتوفر GPU فقط، نفّذ التدريب:
   `python hybrid_training/train_full.py --model-dir /models/qwen3-0.6b --data-dir /secure/jon2-data --approval-manifest /secure/source_approvals.json --output-dir /secure/runs/jon2-qwen3-full-v1 --intended-use research_training --precision bf16`
7. قيّم النسخة الأساسية والنسخة المدربة على نفس مجموعة الاختبار:
   `python hybrid_training/evaluate_helper.py --model-dir /models/qwen3-0.6b --prompts hybrid_training/evaluation_prompts.example.jsonl --output /secure/reports/base.jsonl`
   `python hybrid_training/evaluate_helper.py --model-dir /secure/runs/jon2-qwen3-full-v1/final --prompts hybrid_training/evaluation_prompts.example.jsonl --output /secure/reports/fine-tuned.jsonl`

التدريب الحقيقي يرفض العمل دون CUDA، ويرفض الملفات غير المعتمدة أو المتغيرة، ويحمّل النموذج من المسار المحلي فقط. لا تضف `--trust-remote-code` ولا تفعّل تنزيلًا تلقائيًا.

## تقدير الموارد

لا يمكن تثبيت حد VRAM نهائي من اسم النموذج فقط؛ يتغير حسب طول السياق والـbatch والـoptimizer وإصدار المكتبات. حتى نموذج 0.6B قد يحتاج ذاكرة أكبر من المتوقع عند تحديث كل الأوزان. ابدأ باختبار ذاكرة صغير على الجهاز الفعلي قبل جلسة طويلة. لا يوجد وعد بتوفر GPU مجاني دائم.

## بوابات الجودة قبل اعتماد النموذج المساعد

- اختبار مستقل للفصحى والمصرية، لا يدخل ضمن بيانات التدريب.
- حساب ومنطق وأسئلة متعددة الخطوات ومتابعة سياق.
- مقارنة قبل التدريب وبعده على نفس الأسئلة.
- تقييم بشري لكل المخرجات الحرجة، مع تسجيل الإجابات غير المفهومة والتكرار والهلوسة.
- حفظ model revision وSHA-256 للبيانات والإعدادات وcheckpoint والنتائج.
- لا يُفتح chat ولا يُغيّر إعداد `JON2_CHAT_RELEASE_APPROVED` بسبب نجاح التدريب وحده.
- لا تُستبدل أوزان Jon2 الأصلية ولا تُدمج مع أوزان Qwen.
