# Arabic dialogue candidates — review required

This directory contains newly drafted, original Arabic dialogue examples proposed for Jon2 research.

**Status: CANDIDATE ONLY — NOT APPROVED FOR TRAINING.**

- The JSONL file is deliberately outside `training_data/`, so the existing trainer will not ingest it.
- The examples must be reviewed by the project owner for correctness, naturalness, originality, privacy, and suitability.
- If approved, move a reviewed exact file into the training-data area and create a private source-approval record with its exact SHA-256, character count, reviewer, review date, rights basis, and intended use.
- Do not copy these examples into the held-out evaluation prompts.
- This is a small starter batch, not enough data to make the current model a capable assistant. More diverse, carefully reviewed examples will be needed.

The examples cover Arabic explanation, reasoning, arithmetic, uncertainty, instruction following, safety, summarization, and contextual meaning. A human review is still required; generated examples may contain errors or oversimplifications.
