# Jon2 AI mobile client connection plan

**Status: design only. No model inference or public chat is enabled.**

## Goal

The owner uses an iPhone browser to open the GitHub Pages frontend, send an Arabic message, and receive a response generated by a model running on Jon2-controlled compute.

## Required request path

`iPhone browser -> Jon2 HTTPS application API -> private local model runtime`

The browser must never call the private model route with a permanent bearer token. A token embedded in JavaScript, HTML, GitHub Pages, or browser storage is extractable by visitors and is not a secret.

## Existing API boundary

The private Jais2 route is mounted at:

- `GET /api/jais2/health`
- `POST /api/jais2/chat`

It is disabled by default and requires the server-side `JON2_JAIS2_API_TOKEN`. Keep this boundary. Do not expose that token to the static frontend and do not remove the authentication check to make browser calls succeed.

## Work required before connecting the iPhone UI

1. Resolve the model training-data rights gate and the owner's model-host access approval.
2. Select a compliant host with persistent private model storage and sufficient RAM/VRAM for the exact approved model and runtime.
3. Add a separate public-facing HTTPS application endpoint with a user session mechanism. The session cookie must be Secure, HttpOnly, and SameSite; the model bearer token remains server-side.
4. Add request-size limits, rate limiting, origin checks, abuse controls, and safe error handling to the public-facing endpoint.
5. Keep the model route private to the backend. Do not add the model token to CORS headers or browser requests.
6. Add a frontend setting for the HTTPS application endpoint only after the endpoint is deployed and tested.
7. Verify end-to-end from an iPhone browser: login/session, prompt submission, generated response, logout, unauthorized request rejection, and rate-limit behavior.

## Current honest status

- GitHub Pages is a static frontend; it does not run the Python model server.
- The iPhone is the control device and client, not the host for the selected 8B BF16 model.
- The Jais2 route is code only, disabled by default, and has not completed a real model inference test.
- No permanent free inference host has been verified.
- No public browser-to-model connection is enabled.
