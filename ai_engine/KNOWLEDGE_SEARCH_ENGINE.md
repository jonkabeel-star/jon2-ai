# Jon2 Knowledge Search Engine v1

## What it does

The search engine adds a source-attributed retrieval path to the original Jon2 API:

1. Accept a short factual query in Arabic or a supported language.
2. Detect the likely language and remove common question wrappers before searching.
3. Search public MediaWiki indexes in the query language, with English/Arabic fallback.
4. Fetch up to five article summaries, rank candidates using a transparent local lexical relevance score, and keep source titles and HTTPS URLs attached.
5. Cache the ranked result set in SQLite for 24 hours.
6. Return a source extract only when the best lexical match clears a conservative threshold. Weak matches and empty results do not become answers.
7. For model chat requests that pass the existing release gate, pass the top two extracts and source URLs into the original Jon2 model prompt. The response includes source links.

## API

POST /api/knowledge/search

Request example:

    {
      "query": "ما عاصمة مصر؟",
      "limit": 5
    }

The endpoint does not require a model checkpoint, because it returns retrieved source material rather than claiming to generate a Jon2 answer. The response distinguishes:
- retrieved_source_extract: a short extract from a source, with a citation.
- weak_match: results exist but the lexical match is too weak to present as an answer.
- no_verified_retrieval: no usable result was retrieved.

The response includes answer_type, sources, cached, status, and source_policy. The notice explicitly labels direct extracts as retrieved material, not text generated by Jon2.

## Runtime integration

For factual questions, /api/chat now retrieves up to three results and supplies the best two extracts as reference context to generate_reply. The original Jon2 checkpoint remains the only generator of conversational answers. The existing release approval, checkpoint, inference, and human-quality gates are unchanged. Retrieval does not bypass those gates and does not make public chat ready.

## Storage and privacy

- Cache path follows JON2_KNOWLEDGE_DB_PATH; otherwise it shares the existing private SQLite knowledge database.
- Cache TTL: 24 hours.
- Query length is limited to 500 characters and result count to 1–5.
- Retrieved pages are never copied to the training corpus and never change model weights.
- On ephemeral hosting, cache data may disappear on restart/redeploy.

## Limits

- This v1 uses Wikipedia/MediaWiki as its public retrieval source; it is not a broad web crawler or a Google/Bing replacement.
- Lexical ranking is not semantic understanding or proof of truth.
- Search can fail when the network/source is unavailable, and a missing result must not be filled with an invented answer.
- Current events, financial prices, medical decisions, legal advice, and other high-impact topics need current authoritative sources and careful review. Wikipedia summaries alone are not sufficient evidence for these decisions.
- A source extract is evidence for the user to inspect, not a guarantee that the claim is correct.
- Retrieval improves evidence access; it does not train the original model or repair incoherent model weights.
