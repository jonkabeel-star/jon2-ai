# نشر Jon2 Studio بشكل خاص على Cloudflare Pages

هذه التعليمات تنشر المحرر كمشروع منفصل، ولا تغيّر موقع Jon2 AI الأساسي.

## الحالة الحالية

- مصدر الملفات: المجلد `studio/` على الفرع `jon2-studio-private-bootstrap`.
- لا تدمج هذا الفرع في `main` لمجرد النشر.
- المستودع عام حاليًا؛ لذلك ملفات المصدر المضافة إلى GitHub مرئية لمن يستطيع فتح المستودع. حماية Cloudflare تحمي الموقع المنشور، ولا تجعل مستودع GitHub خاصًا.
- المحرر الحالي يعمل داخل المتصفح ويحفظ محليًا. ليس بعدُ بيئة تشغيل خوادم أو استضافة تطبيقات خلفية.

## 1. إنشاء مشروع Pages مستقل

من لوحة Cloudflare:

1. افتح **Workers & Pages**.
2. اختر **Create application** ثم **Pages** ثم **Connect to Git**.
3. اختر المستودع `jonkabeel-star/jon2-ai`.
4. اسم المشروع: `jon2-studio`.
5. Production branch: `jon2-studio-private-bootstrap`.
6. Framework preset: **None**.
7. Build command: اتركه فارغًا.
8. Build output directory: `studio`.
9. احفظ إعدادات المشروع وابدأ النشر.

لا تضف متغيرات أسرار أو مفاتيح API. لا تستخدم إعدادات تتطلب خطة مدفوعة.

## 2. قفل النشر قبل مشاركة الرابط

بعد إنشاء المشروع، افتح إعداداته واتبع توثيق Cloudflare الرسمي لحماية عنوان `pages.dev`:

1. افتح **Settings** وابحث عن **Enable access policy**.
2. فعّل Access للمعاينات.
3. افتح **Zero Trust → Access → Applications** ثم التطبيق الذي أنشأه Pages.
4. اضبط Public hostname بحيث يغطي عنوان الإنتاج `jon2-studio.pages.dev` نفسه، وليس فقط النطاق الفرعي للمعاينات. في تعليمات Cloudflare الحالية يتم تعديل hostname وحذف النجمة `*` من حقل Subdomain للتطبيق المناسب.
5. أعد تفعيل سياسة المعاينات إذا لزم الأمر، وتأكد من وجود سياسة للإنتاج وأخرى للمعاينات.
6. أنشئ سياسة **Allow** لهوية بريدك أنت فقط، باستخدام بريدك داخل لوحة Cloudflare. لا ترسل البريد أو أي رمز دخول أو سر هنا.
7. لا تضف أي سياسة Allow عامة مثل Everyone أو Emails ending in domain.

مرجع Cloudflare: https://developers.cloudflare.com/pages/platform/known-issues/

مرجع معاينات Pages: https://developers.cloudflare.com/pages/configuration/preview-deployments/

## 3. اختبار الخصوصية قبل الاستخدام

- افتح عنوان الإنتاج في نافذة خاصة وأنت غير مسجل الدخول: يجب أن تظهر صفحة Cloudflare Access أو يُرفض الوصول.
- سجّل الدخول بالهوية المسموح بها: يجب أن يفتح Jon2 Studio.
- جرّب عنوان معاينة الفرع أيضًا؛ يجب أن يكون محميًا.
- إذا أمكن فتح أي عنوان دون تسجيل دخول، أوقف مشاركة الرابط ولا تعتبر النشر خاصًا بعد.

## 4. سياسة التكلفة

- لا تفعّل Workers Paid أو أي ترقية مدفوعة.
- لا تضف بطاقة بغرض تجاوز حدود الخطة المجانية.
- لا تضف مزود AI مدفوعًا أو مفتاح API.
- حدود الخطط المجانية قد تتغير؛ لا يوجد ضمان أن أي خدمة مجانية للأبد. إذا تجاوز الاستخدام حدًا مجانيًا، يجب أن يتوقف الطلب أو يفشل بدل التحويل التلقائي إلى خدمة مدفوعة.

## 5. حدود النسخة الحالية

هذه النسخة محرر HTML/CSS/JavaScript مع معاينة معزولة وتصدير ملفات. الحفظ محلي في المتصفح، وليس مزامنة سحابية. لا تشغّل Python أو Node على خادم، ولا تنشئ VPS أو قواعد بيانات، ولا تنشر تطبيقًا عامًا تلقائيًا. هذه مراحل لاحقة تحتاج تصميمًا واختبارات أمان منفصلة.
